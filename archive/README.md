# Wilhelmina history archive

This directory keeps earlier implementation material for reference only. The active application is `bot.py`, `cogs/`, `services/`, `config/` and the current top-level project documentation. Consult `AGENTS.md` and `README.md` for current decisions.

- `node/`: legacy Node implementation, preserved as history.
- `legacy-tools/early-python-bootstrap/`: old local bootstrapping, repair and push scripts, **not supported operational tooling**.

Do not run old setup/reset scripts on a current checkout. Some contain destructive `git reset --hard`, `git clean -fd`, old branch checkouts or hard-coded rewrites. Historical preservation is not a recommendation to execute them.

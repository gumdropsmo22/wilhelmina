# Wilhelmina — Archived Node Prototype

This directory contains the **archived** Node runtime that previously powered the bot.
It has been removed from the active build and CI as part of cleanup sprint **C1**.

## What changed
- Python is the only supported runtime at the repo root.
- CI and docs no longer reference npm scripts.

cd archive/node

npm start  # STUB: depends on historical scripts
